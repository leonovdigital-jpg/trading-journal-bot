# База знаний бэктестов

Сюда складываются выводы проверок торговых идей на истории — по файлу на актив.
Опровергнутые идеи не удаляются: так их не придётся проверять повторно.

## Файлы

| Актив | Файл | Данные |
|---|---|---|
| US30 (Dow Jones) | [US30.md](US30.md) | TradingView `PEPPERSTONE:US30` |

## Статусы идей

- ✅ **подтверждено** — преимущество над базой устойчиво на достаточной выборке (от ~30 решённых случаев) и на разных периодах;
- ❌ **опровергнуто** — преимущества над базой нет;
- ⚠️ **мало данных** — меньше ~30 случаев, вывод предварительный;
- 🔄 **в работе** — правила уточняются или прогон не закончен.

В раздел «Рабочие правила» вверху файла актива попадают только ✅.

## Как идёт проверка

1. Идея своими словами → формализация в точные правила → подтверждение пользователем.
2. Расчёт — Pine-индикатор в [`../pine/`](../pine/) на графике TradingView (layout `us30_backtest`).
   Каждый случай индикатор пишет строкой в Pine Logs; логи собираются в `reports/<период>_<идея>/pine-logs.json`.
3. Отчёт — `python3 tools/report.py reports/<папка>`: статистика, базовая частота, срезы, таблица случаев,
   картинка каждого дня (скриншот графика с индикатором).
4. Вывод — в файл актива: статус, цифры, ссылка на отчёт, история прогонов.

## Две базы для сравнения

Одного «% отработок» мало: важно, насколько он выше того, что получилось бы без сигнала.

- **База по сессиям** — тот же критерий отработки, посчитанный от закрытия каждой свечи тех же сессий, без условия.
- **Случайное блуждание** — для критерия «какая из двух целей первой»: шанс дойти до цели A раньше цели B
  при случайном движении равен `расстояние до B / (расстояние до A + расстояние до B)`.
  Эта база строже: она учитывает, что после закрепа ближайшая цель по направлению обычно ближе цели против.

## Ограничение данных

Тариф TradingView Essential хранит на графике ≈ 10 000 часовых свечей (на сентябрь 2026 — примерно с 2 января 2025),
и это окно каждый день сдвигается вперёд. Старшие таймфреймы (D/W/M) доступны на всю глубину.
Прогоны по H1 нужно делать, пока нужный период ещё в окне.
