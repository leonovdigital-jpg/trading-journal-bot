# Быстрый старт

## macOS приложение (веб)

### 1️⃣ Первый запуск

```bash
cd mac
npm start
```

Откроется сервер на `http://127.0.0.1:3333`

### 2️⃣ На локальной сети (iPhone в одной Wi-Fi)

```bash
hostname -I  # узнать IP мака
# Затем на iPhone открыть: http://<IP>:3333
```

### 3️⃣ Добавить на экран "Домой" (iPhone)

- Safari → http://<IP>:3333
- Поделиться → Добавить на экран "Домой"

---

## iOS приложение

### 1️⃣ Создать проект в Xcode

```bash
# Xcode → File → New → Project
# iOS → App
# Language: Swift, Interface: SwiftUI
```

### 2️⃣ Скопировать файлы

Скопировать в Xcode проект:
- `ios/ChecklistApp.swift`
- `ios/ContentView.swift`
- `ios/ChecklistViewModel.swift`

### 3️⃣ Запустить

Cmd+R на симуляторе или устройстве

---

## Чек-лист работает так:

1. **Вопрос 1** → нажимаем кнопку (зелёная/жёлтая/красная)
2. Если красная → **СТОП** (доступ запрещён)
3. Если зелёная/жёлтая → **Вопрос 2**
4. ... все 6 вопросов ...
5. Если все пройдены → **ДОПУСК РАЗРЕШЁН** → Match Trader открывается

---

## Логирование

**macOS:** `mac/db/checklist.db` (SQLite)
**iOS:** UserDefaults (локально на устройстве)

Каждая попытка логируется с датой, временем, ответами и результатом.
